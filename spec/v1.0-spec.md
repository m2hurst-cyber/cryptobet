# Macro Model v1.0 — Frozen specification

## Non-negotiables

- **Universe:** 11 SPDR sector ETFs — XLK, XLF, XLE, XLI, XLV, XLY, XLP, XLU, XLB, XLRE, XLC.
- **Rebalance frequency:** weekly. Signals published Sunday 21:00 UTC for Monday/next market open. Never change frequency within v1.0.
- **Rule:** rank sectors by composite score. Top 3 = OW, bottom 3 = UW, middle 5 = Neutral. No conditional exceptions. Exact ties break alphabetically by ticker.
- **Benchmark:** equal-weight basket of all 11 sectors. Never SPY.
- **Log:** `data/model_log.jsonl` is append-only; past signal fields are immutable. Forward returns are backfilled only into `forward_returns`. Official weekly publications are additionally preserved append-only in `data/weekly_signal_log.jsonl` for auditability.
- **Version:** v1.0. Any change to factors, formulas, exposure matrix, or ranking rule requires v2.0, a new inception date, and a separate log. Versions are never merged.
- **Public live flag:** ships OFF. The public page shows “Model spinning up — first live call 2026-09-20 21:00 UTC. Methodology available now.” Human flips the flag only after review of the first 10 days of commits.

## Sector score

`sector_score_i = Σ_j (exposure_ij × factor_j)`

The exposure matrix in `spec/exposure-matrix.csv` is frozen for v1.0.
